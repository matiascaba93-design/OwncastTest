SUMMARY OF ALL CHANGES
================================================================

We implemented mobile-specific toggles for chat and extra page content in Owncast.
This allows administrators to independently control whether chat and custom content
are visible to mobile viewers, separate from desktop settings.

- mobileExtraPageContentEnabled: true (enabled by default)

- mobile_chat_enabled (boolean)
- mobile_extra_page_content_enabled (boolean)

API Endpoints:
- POST /api/admin/config/mobile/chat/enabled
  Body: {"value": true} or {"value": false}
  Requires: Admin authentication

  Body: {"value": true} or {"value": false}
  Requires: Admin authentication

Client Config Response:
- GET /api/config includes:
  * mobileChatEnabled: boolean
  * mobileExtraPageContentEnabled: boolean

- GET /api/admin/serverconfig includes:
  * mobileChatEnabled: boolean
  * mobileExtraPageContentEnabled: boolean
